# 🦜 CrazyParrot

> English / 中文

**CrazyParrot is a local-first desktop coding agent. You describe the task, it reads your project's rules first, then edits files, runs commands, and tests — all with your approval, evidence, and one-click rollback.**

## What is CrazyParrot?

CrazyParrot is a desktop app that brings an AI coding assistant directly to your own projects — no cloud upload, no account required. Instead of pasting code into a website, you let the agent work inside your project folder, following your project's own conventions.

## Why CrazyParrot?

- **Local-first** — everything runs on your computer. Your code and API keys never leave your machine.
- **Respects your project** — CrazyParrot reads your `README.md` and `AGENTS.md` first, so it follows your conventions instead of guessing.
- **You stay in control** — every change is shown to you, and anything risky needs your approval before it runs.
- **Reversible** — each task gets a snapshot of your project; you can roll back with one click anytime.
- **No Git required** — it works on any local folder, even without version control.

## How it works

1. **Open a project** — create a new one or import an existing folder.
2. **Connect a model** — add your own OpenAI Chat Completions or Anthropic Messages compatible API key in Settings.
3. **Describe your task** — tell CrazyParrot in plain language what you want to do.
4. **Review and approve** — check the proposed changes, then approve to let it run.

## Privacy & Security

- Your API key is stored locally and never written into project files or logs.
- CrazyParrot never uploads your project content anywhere.
- Risky operations always wait for your approval.

## Current Limitations

- The first release does not include accounts, cloud sync, team collaboration, or remote execution.
- No signed installers or automatic updates yet.

# 🦜 CrazyParrot

> English / 中文

**CrazyParrot 是一款本地优先的桌面编码 Agent。你描述任务，它先读取你项目的规则，再修改文件、运行命令和测试——全程需要你审批，提供证据，并支持一键回退。**

## CrazyParrot 是什么？

CrazyParrot 是一款桌面应用，把 AI 编码助手带到你自己的项目里——不传云端、无需账号。你不用再把代码粘贴到网站上，而是让 Agent 在你的项目文件夹里直接工作，并遵循项目自身的约定。

## 为什么选择 CrazyParrot？

- **本地优先** —— 一切都在你自己的电脑上运行。你的代码和 API 密钥永远不会离开你的机器。
- **尊重你的项目** —— CrazyParrot 会先阅读你的 `README.md` 和 `AGENTS.md`，遵循你的项目约定，而不是靠猜。
- **你始终掌控** —— 每次改动都会展示给你，有风险的操作必须经过你的批准才会执行。
- **可以回退** —— 每个任务都会为你的项目创建快照，随时可以一键回退。
- **不需要 Git** —— 任何本地文件夹都能使用，即使没有版本控制。

## 怎么使用

1. **打开项目** —— 新建一个项目，或导入现有文件夹。
2. **接入模型** —— 在设置中添加你自己的 OpenAI Chat Completions 或 Anthropic Messages 兼容 API 密钥。
3. **描述任务** —— 用自然语言告诉 CrazyParrot 你想做什么。
4. **审阅并批准** —— 检查它提议的改动，批准后即可执行。

## 隐私与安全

- 你的 API 密钥只保存在本地，绝不会写入项目文件或日志。
- CrazyParrot 不会把你的项目内容上传到任何地方。
- 有风险的操作总是等待你的批准。

## 当前限制

- 首版不提供账号、云同步、团队协作和远程执行。
- 暂无签名安装包和自动更新。
